# Retail Sales Analysis Dashboard

An interactive dashboard that turns raw retail sales data into clear business insights. Data is cleaned and transformed with **Pandas**, stored in **SQLite**, and explored through a **Streamlit** app with **Plotly** charts.

# Retail Sales Analysis

## 📊 Project Overview

This project analyzes retail sales data using Python, SQL and Power BI
to identify sales trends, profitable categories, regional performance
and customer behavior.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI
- Jupyter Notebook
- Streamlit
